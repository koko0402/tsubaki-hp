# 椿@お絵描き局

木目の壁に、椿の画鋲で絵が留めてある展示サイト。

---

## いますぐ試す

見る側 → `index.html` をブラウザで開く
投稿する側 → `kanri-7f3a2c/index.html` を開く

**設定なしで、そのまま投稿を試せます。** 画像を選んで保存すれば、サイト側にすぐ出ます。
ただしこの段階では、保存先はあなたの端末のブラウザの中だけです（他の人には見えません）。

実際に公開するには Supabase の設定が要ります。→ **[SETUP.md](SETUP.md)**

## 2つのモード

サイトは `config.js` の中身を見て、自動でどちらかになります。
**画面も操作も同じ**で、保存先だけが変わります。

**① 見本モード**（`config.js` が空 ← いまここ）

- 保存先は、あなたの端末のブラウザの中（IndexedDB）
- 投稿・編集・削除・❤・コメント、全部ふつうに動きます
- でも **他の人には何も見えません**。使い勝手を確かめるためのものです
- 中身は最初の一度だけ `js/data.js` から写されます。投稿ページの「見本データに戻す」でいつでも最初の状態に戻せます

**② 本番モード**（`config.js` を設定済み）

- 保存先が Supabase になる
- ❤・コメント・閲覧数が **全員で共有される**
- 投稿ページにログインが必要になり、投稿できるのは登録した2人だけになる

見本モードのときは、サイトの上と投稿ページに小さくその旨が出ます。

## 投稿する（投稿者側）

`kanri-7f3a2c/index.html` を開きます。サイトのどこからもリンクしていません。

4つのタブがあります。

- **絵** — 画像を選んで、タイトル・描いた人・日付・タグ・ひとことを入れて保存。
  「おすすめに入れる」にチェックすると、ホームのいちばん上に出ます。
  下に投稿済みの一覧が出て、**編集・おすすめの切替・削除**ができます
- **ブログ** — 記事の投稿・編集・削除。「一番上に固定」でお知らせ扱い
- **サイト設定** — サイト名、ひとこと、SNSリンク、描いた人の一覧、
  おすすめの文章、YouTube動画ID、コメントの条件。
  いちばん下に **背景の絵**（描いた背景への差し替え）があります
- **コメント** — 新しい順に100件。荒れたものをここから消せます

見本モードでは、右上に「**見本データに戻す**」が出ます。
試しに投稿したものを全部消して、最初の状態に戻せます。

本番モードにすると、この画面はそのままログイン付きの本番用になります。
やり方は変わりません。

## 画面の形

LINE VOOM と同じ形にしてあります。**上のバー／縦に流れるフィード／下のナビ** の3段構成です。

```
┌──────────────────────────┐
│ 🌺 椿@お絵描き局      [プロフィール] │ ← 上のバー（ずっと出ている）
├──────────────────────────┤
│  製作者のおすすめ  → → →          │ ← 横に流れる
│  [新着][人気]            [ぜんぶ▾] │ ← スクロールしても貼り付く
│ ┌────────────────────┐  │
│ │ 🌺 椿  3時間前            │  │
│ │ 夕暮れの帰り道             │  │
│ │ ［　　　絵　　　］          │  │
│ │ 👁312 ❤48 💬2            │  │
│ │  ♡いいね  💬コメント  ↗シェア │  │ ← 開かずにその場で押せる
│ │ 🌟ななし 空の色すき         │  │
│ │ (icon)[コメントを書く    ][送信]│  │
│ └────────────────────┘  │
│            ⋮ 下に行くと自動で続き    │
├──────────────────────────┤
│ ホーム   ギャラリー   ブログ   わたし │ ← 下のナビ
└──────────────────────────┘
```

### 4つのページ（下のナビで切り替え）

- **ホーム** — VOOM風のフィード。下までスクロールすると自動で続きが読み込まれます
- **ギャラリー** — 木の壁に椿の画鋲で留めた展示
- **ブログ** — お知らせと記事
- **わたし** — 自分のプロフィールと、❤ を押した絵の一覧

### フィードの1件でできること

- **いいね** — 開かずにその場で押せます
- **コメント** — 下の入力欄からそのまま書けます。新しいコメントが2件ずつ見えます
- **シェア** — その絵に直接飛べるリンクをコピーします（`?w=作品id`）
- 絵を押すと拡大表示

### そのほか

- 拡大表示（ホイール／ピンチで拡大縮小、ドラッグで移動、ダブルクリックで戻す）
- 「新着」／「人気」の切り替え、描いた人での絞り込み
- **タグでの絞り込み** — タグを押すと、そのタグの絵だけになります。フィードの `#タグ` からも押せます
- 閲覧数・ハート数・コメント数の表示
- 製作者のおすすめ（横に流れる＋YouTube）
- SNS等の外部リンク
- **背景の絵の差し替え**（描いた背景を貼れる。設定しなければ木目のまま）
- **ホームに戻る** — 少し下にスクロールすると右下に出ます。上のバーのサイト名でも戻れます
- キーボード操作（`←` `→` 送り、`Esc` 閉じる、`+` `-` `0` 拡大）
- 管理ページから投稿・編集・削除、サイト設定の変更、コメントの削除

## 背景を描いた絵に変える

管理ページ → **サイト設定** → いちばん下の「背景の絵」。

| 項目 | 何をするか |
|---|---|
| 画像を選ぶ | パソコンから背景の絵を選んで貼ります |
| ファイルの場所を直接書く | `images/` に置いた絵を使うとき。例 `images/haikei.png` |
| 敷き方 | **全面に伸ばす**（一枚絵むき）／**並べて敷き詰める**（模様むき） |
| 暗くする度合い | 背景の上にかける黒い幕の濃さ。0〜70% |
| 今の背景 | 保存する前に、その場で見え方を確かめられます |

**何も入れなければ木目のままです。**「木目に戻す」でいつでも戻せます。

> **暗くする度合いは必ず確かめてください。**
> 明るい絵をそのまま敷くと、白い文字が読めなくなります。
> 初期値は 25% です。読みにくいと感じたら上げてください。
> 逆に暗い絵なら 0% でも大丈夫です。

絵の大きさは **横1600px以上** を目安に。小さいと画面いっぱいに伸ばしたときにぼやけます。
「並べて敷き詰める」を選ぶときは、**上下左右がつながる絵**（シームレス）だと継ぎ目が出ません。

## コメントとプロフィール

**なまえとアイコンを作らないとコメントできません。**

ヘッダーの「プロフィールを作る」から、なまえ（20文字まで）とアイコン（8種類×8色）を選びます。
決めるまでコメント欄は開かず、「プロフィールを作る」ボタンだけが出ます。
作ったプロフィールはその人のブラウザに保存され、あとから変えられます。

Google と紐付けることもできます（任意）。紐付けると Google の名前と写真がそのまま使え、
コメントに小さな ✓ が付きます。`config.js` の `enableGoogleLogin` を `true` にすると出ます。

### 効き目の違い（大事なところ）

| やり方 | 止まる場所 | どれくらい効くか |
|---|---|---|
| なまえ＋アイコン必須（初期設定） | 画面側 | **お願いベース。**その気になれば回避できます。ふつうの荒らし避けには十分 |
| Googleログイン必須 | サーバー側 | **本当に弾きます。**APIを直接叩いても通りません |

後者は管理ページの **サイト設定** →「コメントに Google ログインを必須にする」で
いつでも切り替えられます。荒らされてから切り替えても大丈夫です。

## 合言葉（ログイン）について

> 「合言葉の入力画面自体は誰でも見られるよね？編集できないとしても。だから別がいい」

問題は 2 つあって、片方は隠すことで、もう片方は隠しても解決しません。

### ① 入口が見えてしまう → URL を隠した

管理ページはサイトのどこからもリンクせず、推測できないURLに置いてあります。

```
kanri-7f3a2c/index.html
```

トップページからは辿り着けません。ただしこれは「鍵」ではなく「目立たない裏口」です。

### ② 合言葉そのものが読めてしまう → ここが本命

画面側のJavaScriptで合言葉を判定すると、**ソースを見れば合言葉が読めます。**
URLを隠しても変わりません。

さらに、管理ページを完全に隠しても、データの保存先が「誰でも書き込める」設定なら
ページを経由せず直接書き換えられます。**守るべきなのは画面ではなく保存先です。**

### いまの作り

- 合言葉の確認は **Supabase のサーバー側** で行う（画面側では判定しない）
- データベース側に「**書けるのは `admins` に載っている人だけ**」というルールを入れてある
  （`supabase/schema.sql` の後半がそれです）
- 読み込み（絵を見る・❤・コメント）は誰でもOK

こうすると、ログイン画面が人目に触れても問題ありません。
X も pixiv もログイン画面は誰でも見られますが、それで困っていないのと同じです。
**「見えない」ことではなく「サーバーが弾く」ことで守っています。**

見た目としてログイン入口を出したくない、というのは好みの話なので、
隠しURLはそのまま残してあります（両立します）。

### ついでに気をつけること

- `config.js` に入れる **anon キーは公開前提の値** です。ソースに出て構いません。
- **`service_role` キーは絶対に貼らないでください。** あれは全権限の鍵です。
- Supabase の設定で **「新規登録を許可」をオフ** にしてください（[SETUP.md](SETUP.md) 手順4）。

## 最初に入っている中身を変えたいとき

`js/data.js` は、見本モードの **初期値** です。
ふだんの投稿は投稿ページからやれば足りるので、ここを触る必要はありません。

触るのは、「試した結果を全部消して、別の初期状態から始めたい」ときだけです。
書き換えたあと、投稿ページの「見本データに戻す」を押すと反映されます。

```js
{
  id: 'w007',
  title: '絵のタイトル',
  file: 'images/自分のファイル名.png',
  artist: 'tsubaki',             // tsubaki（椿） or kanri（管理人）
  date: '2026-08-13',
  desc: 'ひとこと',
  tags: ['風景'],
  baseViews: 0, baseHearts: 0,
  comments: [],
},
```
